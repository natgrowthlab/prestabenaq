# PrestaBenaq

MVP estático de PrestaBenaq, una plataforma de soluciones de liquidez e inversión con una experiencia digital centrada en claridad y confianza.

## Ejecutar localmente

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.

## Contenido

- `index.html`: página principal y estructura semántica.
- `styles.css`: sistema visual responsive.
- `app.js`: simulador de crédito interactivo.
- `PRESTANZA_PRODUCTOS_FINANCIEROS.md`: benchmark público de productos financieros de referencia.
- `design-system/prestabenaq/MASTER.md`: decisiones de diseño base.

## Nota

Las tasas, métricas y montos del MVP son ilustrativos. Antes de operar, el producto requiere revisión legal, de cumplimiento, riesgo, privacidad y contratos aplicables.
